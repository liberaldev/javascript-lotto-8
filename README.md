# javascript-lotto-precourse
무작위로 배정된 로또 번호를 입력받은 당첨번호와 얼마나 일치하는지 알려주는 어플리케이션이다.

## 기능 목록
- [x] 구입 금액 입력
- [x] 입력한 구입 금액 유효성 검사 및 잘못된 값을 입력했다고 판정될 경우 다시 입력 받기
- [x] 입력한 구입 금액에 따라 임의의 번호 로또 구입
- [x] 구입한 로또들의 번호를 출력. 이때 각 로또들의 번호는 오름차순으로 출력.
- [x] 당첨 번호 입력
- [x] 입력한 당첨 번호 유효성 검사 및 잘못된 값을 입력했다고 판정될 경우 다시 입력 받기
- [x] 보너스 번호 입력
- [ ] 입력한 보너스 번호 유효성 검사 및 잘못된 값을 입력했다고 판정될 경우 다시 입력 받기
- [ ] 당첨 내역 및 수익률 출력
